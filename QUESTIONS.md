# Open questions index

A lista normativa de perguntas abertas está em [`docs/discovery/OPEN_QUESTIONS.md`](docs/discovery/OPEN_QUESTIONS.md).

Use este arquivo como porta de entrada para dúvidas que exigem decisão humana. Nenhuma pergunta deve ser “resolvida” por inferência silenciosa; quando uma resposta mudar domínio, segurança clínica, retenção, identidade ou integração, atualize Discovery → PRD → SPEC → tests → Build Plan.

Prioridade imediata:

- política e fallback de resultado crítico;
- ownership de liberação, correção e revisão;
- início/pausa/fim de SLA;
- modelo de amostra/accession;
- sistema mestre de Patient/Encounter;
- autenticação/provisionamento;
- retenção/LGPD e canal de notificação crítico;
- comportamento em alta/transferência/cancelamento parcial.
